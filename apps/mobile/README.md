# Post Cards mobile app

The Expo app targets iOS and Android only. Web is intentionally not supported.

From the repository root:

```bash
pnpm run dev
```

This starts the server and opens the iOS app in the simulator. To run a single target:

```bash
pnpm run dev:mobile
pnpm --filter @post-cards/mobile android
pnpm run dev:server
```

The simulator needs a development build installed. Create it once with:

```bash
pnpm --filter @post-cards/mobile exec expo run:ios
```

The native `ios` and `android` directories are generated by Expo and are not committed.
